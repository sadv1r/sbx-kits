# omp

Run [omp](https://omp.sh), a terminal coding agent, in a Docker Sandbox.

## Usage

```sh
sbx run ghcr.io/sadv1r/omp /path/to/project
```

Or from a git URL targeting this repo:
```sh
sbx run 'git+https://github.com/sadv1r/sbx-kits.git#dir=omp' /path/to/project
```

Or with a local clone of this repo:
```sh
sbx run ./omp /path/to/project
```
